# Product Sheet: Brunner Fina Soft

## Product Name
Fina Soft

## Description
A slender, comfortable conference and office chair meeting high demands. Available as a swivel chair or cantilever, with height adjustment or automatic return mechanism. The high-back version offers added comfort for meetings.

## Overview
Features dynamic spring steel linkage with elastomer damping, fully upholstered shell, and multiple base and armrest options. Designed by Wolfgang C.R. Mezger.

## Types
- Conference Easy Chair (multiple armrest and height options)
- High-back chair versions
- Cantilever frame chairs, stackable options available
